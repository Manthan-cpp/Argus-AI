System Overview & Architecture

Argus AI is engineered as a unified Full-Stack Dart ecosystem cleanly segregated into three primary packages:

1. Geometric Core Engine argus/argus_engine/

Zero-dependency pure Dart library implementing the Jordan curve theorem ray-casting algorithm for arbitrary $N$-point polygon collision and deterministic natural language rule parsing.

2. Streaming Backend Service argus/argus_server/

High-concurrency Dart backend handling streaming WebSocket telemetry batches, managing background countdown escalation timers, and persisting incidents to PostgreSQL.

3. Tactical Flutter Control Room argus/argus_flutter/

60 FPS CanvasKit web interface with interactive polygon zone editing, real-time MediaPipe skeletal pose overlay, fall risk scoring, and priority-ranked incident dispatch.

Guided Code Tour (Key Stops)

Navigate through the source code along the primary telemetry route:

Stop 1: Ray-Casting Point-in-Polygon Mathematics
argus/argus_engine/lib/src/geometry/polygon.dart Polygon.containsPoint(Point point)
Implements the ray-casting algorithm based on the Jordan curve theorem. For any arbitrary $N$-point polygon, casts an infinite horizontal ray from the coordinate point and counts edge intersections. Odd count indicates interior inclusion; even count indicates exclusion.
Stop 2: High-Throughput Streaming & Escalation Timers
argus/argus_server/lib/src/endpoints/signal_endpoint.dart SignalEndpoint.streamSignals(StreamingSession session)
Receives high-frequency telemetry batches over WebSockets, filters noise, checks against active security rules, records critical incidents in PostgreSQL, and spawns asynchronous countdown workers to enforce safety escalation protocols.
Stop 3: Tactical Incident Queue & Operator Dispatch
argus/argus_flutter/lib/features/dispatch/incident_dispatch_room.dart IncidentCard & EscalationTimer
Renders real-time priority-ranked incident cards with forensic video snapshots, active countdown clocks, and instant operator acknowledgment controls that broadcast cancellation events back across the Dart backend.

A Practice to Reuse: Contract-First Pure Dart Isolation

Decouple Core Algorithms From Platform Frameworks

By isolating geometric math and natural language parsing in a zero-dependency Dart package (argus_engine), the core business logic remains 100% testable through sub-second unit tests without needing a running database, Flutter UI runner, or browser WebAssembly runtime.

Why it matters for future projects: On any AI or computer vision project, validating edge algorithms deterministically with unit tests before wiring into UI widgets prevents hours of complex debugging across WebSockets and rendering pipelines.
